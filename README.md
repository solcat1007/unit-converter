# 单位换算器 (Unit Converter) v2.0

单文件 PWA 单位换算工具，纯前端、离线可用。

## 🆕 v2.0 更新

- 新增 **角度 / 压力 / 能量** 三大类别，时间类别扩充到月、年
- 新增 **换算历史**（localStorage 保存最近 30 条，点击即可还原）
- 新增 **长按结果复制**（也支持双击复制），并带复制提示
- UI 全面美化：卡片式布局、强调色结果区、响应式网格
- 注入 SOLCAT 彩蛋引擎，每个项目都有专属彩蛋

## 功能

- **十大类别**：长度、重量、温度、面积、体积、时间、速度、数据存储、角度、压力、能量
- **双向换算**：任意选择源与目标单位，一键交换
- **实时计算**：输入数值即时换算，自动处理极小/极大数值的科学计数法
- **温度专用公式**：摄氏 / 华氏 / 开尔文非线性换算
- **中英文切换**：类别名称与界面文案同步切换
- **本地历史**：换算记录持久化，清空/还原一步到位

## 使用方法

1. 用浏览器打开 `index.html`（或安装为 PWA 离线使用）
2. 选择类别，输入数值，选择「从」「到」单位
3. 结果实时显示；长按（或双击）结果区即可复制
4. 点击下方历史记录可一键还原当时的换算

## 🥚 彩蛋秘籍

通用秘籍（所有 SOLCAT 应用通用）：

| 操作 | 效果 |
|------|------|
| ↑ ↑ ↓ ↓ ← → ← → B A | 全屏彩带烟花 |
| 连点标题 5 次 | 开发者模式面板 |
| 输入 `solcat` 后回车 | 赛博朋克隐藏主题 |
| Ctrl + Shift + T | 切换赛博朋克主题 |

**本作专属**：解锁任意彩蛋后，换算结果会临时变成「42 —— 万物终极答案」。

## 技术栈

纯 HTML / CSS / JavaScript，localStorage 持久化，Service Worker 离线缓存。
